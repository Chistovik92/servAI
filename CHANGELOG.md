# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [SemVer](https://semver.org/lang/ru/).

## [1.1.0] — 2026-10-13

### Добавлено
- Установка одной командой: `curl -fsSL .../install.sh | sudo bash`; вопросы идут через `/dev/tty`.
- `ai-keys` — интерактивный ввод API-ключей (скрытый ввод, ссылки на страницы получения ключей, безопасная запись в `~/.env.ai`).
- Запрос пароля веб-IDE при установке; итоговая сводка со ссылкой/командой туннеля.
- Провайдер `openrouter` в `ai`; tmux-сессия `ai-quad` с мышью.
- Переменная `CONFIGURE_KEYS=0` для неинтерактивной установки.
- `ai-models`: выбор моделей по спискам официальных API Anthropic, OpenAI, Gemini, DeepSeek, OpenRouter; модели применяются в режиме `api`.
- DeepSeek как харнесс: `ai deepseek claude` (Claude Code на эндпоинте `api.deepseek.com/anthropic`) и `ai-bench` (mini-swe-agent + SWE-bench).
- Поддержка Ubuntu 24.04 и новее, Debian 12 и новее.

### Изменено
- Ubuntu 22.04 больше не поддерживается (минимум 24.04).
- Aider и harness ставятся через `uv` с Python 3.12 вместо `pipx`/системного python: работает на дистрибутивах с Python 3.13+.

### Исправлено
- `ai codex api` перезаписывал подписочную авторизацию Codex: теперь отдельный `CODEX_HOME`.
- `umask 077` на всём скрипте делал каталоги code-server и unit-файл недоступными для рабочего пользователя; теперь `umask 022`, секреты защищены явными `chmod 600`/подоболочкой.
- Пароль веб-IDE экранируется в YAML.
- `ai deepseek` без режима больше не падает с «Использование».
- Предупреждение, если harness включён без Docker.

## [1.0.0] — 2026-10-13

### Добавлено
- Полное описание проекта в `README.md` на русском языке.
- Лицензия MIT, `.gitignore`, `.gitattributes` (принудительные LF для `*.sh`).
- Этот журнал изменений.

### Исправлено
- Файл `Install.sh` переименован в `install.sh`: имя совпадает с командой в сообщениях скрипта (`sudo bash install.sh`) и работает на регистрозависимых системах.
- `ai`: команда вида `ai claude --resume` больше не принимает флаг за режим (`native`/`api`); по умолчанию используется `native`.
- Проверка наличия `aider-chat` не использует `pipx list --short`, которого нет в pipx из Ubuntu 22.04.
- Сводка установленных версий больше не обрывает установку, если `npm list` или `pipx list` вернули ненулевой код.
